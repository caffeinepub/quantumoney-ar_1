# Specification

## Summary
**Goal:** Unify Quantumoney.app with QuantumoneyAR.app through a shared UserID-keyed backend, a rebuilt animated HOME page, a unified Profile page, a professional Central Bank dashboard, synchronized Map and AR pages, a clean footer, and consistent yellow design tokens throughout.

**Planned changes:**

- **Footer:** Replace content with only "© 2026 Quantumoney. All rights reserved." and "By HTgamers"; add WhatsApp, X (Twitter), Telegram, and Instagram share buttons; remove all Caffeine/caffeine.ai references from Footer, index.html meta/OG/Twitter tags, and all other frontend source files; increase footer padding/font size slightly for visibility.
- **HOME page:** Extend the SpaceBackground component with animated stars, planets, comets, and meteorites; add alternating golden ICP and QMY coin animations that grow from center outward every 5 seconds (3-second duration each); add "Welcome to the Quantumoney World" welcome message; add "Install AR App" CTA button linking to https://QuantumoneyAR.app in a new tab; preserve existing hero sections and feature grid.
- **Profile page:** Rebuild as a single unified profile with tabs covering: editable player name, profile photo upload/preview/save, wallet section (Login ID/UserID, ICP balance, QMY balance, Send/Receive panels), full transaction history, vesting breakdown and welcome bonus card, and XP/level game stats; remove any separate wallet page navigation; complete all currently empty or placeholder tab panels.
- **Backend (main.mo):** Introduce stable Principal → UserID mapping (auto-incremented integer); key all player profile, wallet, coin, monster, XP, transaction, and vesting records by UserID; on first registration automatically award 1000 QMY (100 unlocked + 900 locked on a 100/month vesting schedule) and 100 XP; welcome bonus awarded once per UserID.
- **Backend (migration.mo):** Generate a migration file that transforms existing Principal-keyed state maps to UserID-keyed maps idempotently without data loss.
- **Central Bank page:** Rebuild as a professional dashboard with: geographic coin/monster distribution visualization, vesting table and chart, burn history table, bonuses and unlock mechanics, supply charts, tokenomics stats, explanatory accordion, and download buttons for tokenomics CSV, vesting CSV, burn history CSV, and QMY document; query Carteira A canisters (QMY Ledger: 5o54h-giaaa-aaaad-aentq-cai; Governance: nemlr-6aaaa-aaaan-q32la-cai) with simulated fallback.
- **Map page:** Update data source to fetch coin and monster markers from the same Carteira A backend canisters used by the AR page, keyed by UserID, with no visual layout changes beyond the data source update.
- **AR page:** Add camera permission request on /ar route open; add "Lock/Unlock QMY" and "Capture Monster" action buttons; persist captured monsters and coin lock state to the shared UserID-keyed backend; minimize layout changes.
- **Canister IDs audit:** Ensure all five Carteira A canister IDs (Frontend: crjop-jyaaa-aaaah-atfaq-cai, Gold Paper: whu4t-kiaaa-aaaah-qsc5q-cai, Governance/Treasury: nemlr-6aaaa-aaaan-q32la-cai, Logic: ckmsk-taaaa-aaaah-atfca-cai, Ledger QMY: 5o54h-giaaa-aaaad-aentq-cai) are correct and consistent in CanisterArchitecturePanel, TechnicalValidationPanel, TechnicalPage, and all hook/client files.
- **Design tokens:** Apply yellow text and thin yellow borders consistently to all new and updated components; maintain transparent glass-panel style across Profile, Central Bank, and Map pages.

**User-visible outcome:** Users visiting Quantumoney.app see a richly animated space HOME page with coin effects and an AR app install button; a single unified Profile page containing wallet, vesting, and game stats; a fully rebuilt Central Bank dashboard with downloadable data; a map and AR experience where coins and monsters are synchronized with the shared backend; a clean footer with social share buttons and no external branding; and consistent yellow/transparent styling throughout.
